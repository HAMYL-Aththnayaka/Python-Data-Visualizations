# Matplotlib Practice

A personal reference repository containing data visualization practice scripts and Jupyter Notebooks using Python's `matplotlib.pyplot` and `numpy` libraries.

## Contents

* **Basic Plots:** Line graphs and simple data plotting with markers, grids, and line styling (`V1`, `V2`, `V3`, `V4`).
* **Bar Charts:** Categorical data visualization (`V5(barchart)`).
* **Pie Charts:** Circular percentage breakdowns with custom explosion and shadows (`V6(pie chart)`).
* **Scatter Plots:** Multi-variable relationship mapping and correlation plotting (`V7(scatter chart)`).
* **Histograms:** Distribution of numerical data across intervals (`V8(Histograms)`).
* **Subplots:** Managing multiple plots within a single figure canvas (`V9 (subplots)`).
* **Pandas Integration:** Plotting directly from DataFrame objects loaded from CSV files (`V10 (matplotlib and pandas)`).

## Source Material

The code and concepts in this repository were built by following along with the 1-hour Matplotlib tutorial video by **Bro Code** on YouTube.
